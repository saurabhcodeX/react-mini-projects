# React Mini Projects

A collection of React.js mini projects built while learning frontend development using Vite and Tailwind CSS.

## Projects

### 🎨 Color Changer

* Change background color with one click
* Built using React useState

### 🔐 Password Generator

* Generate secure passwords
* Custom password length
* Uppercase, lowercase, numbers, symbols
* Password strength indicator
* Copy to clipboard

### 💱 Currency Converter

* Convert currencies in real time
* API integration
* React state management

## Tech Stack

* React.js
* Vite
* Tailwind CSS
* JavaScript
